**Esta pasta não faz parte do projeto ativo.** Nenhum código, ferramenta ou fluxo do Spec Kit deve lê-la. Só a consulte quando o autor pedir.

| Conteúdo | Origem |
|---|---|
| `specs/001-catalogo-cartas/` | Spec e checklist da feature. O `plan.md` é o template sem preencher |
| `assessment/tcg-programacao/` | Avaliação da ideia (intake, research, problem, concept, decision) |
| `PROMPT_TCC-tcg.md` | Especificação do projeto antes da mudança de conceito |
| `constitution-v1.0.0.md` | Constituição vigente durante o conceito TCG |

A tag `arquivo/tcg-v0` e a branch `feat/001-catalogo-cartas` guardam o estado original.

Para retomar o TCG, inicie uma nova feature pelo Spec Kit e reavalie este material em relação ao conceito vigente.
