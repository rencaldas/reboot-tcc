# Atribuições de fontes de dados

Cada fonte externa usada para gerar o catálogo de cartas ou qualquer outro dado do projeto entra aqui, com fonte, termos de uso e licença **verificados na própria fonte** — nenhum termo é presumido.

Este arquivo será preenchido durante a feature `catalogo-cartas` (ver `PROMPT_TCC.md`, seção 7), à medida que cada fonte de dados for integrada ao pipeline.

## Formato de cada entrada

```
## Nome da fonte

- **URL:** 
- **Licença:** 
- **Termos relevantes:** 
- **Data de verificação:** 
- **Uso neste projeto:** 
```

## Fontes conhecidas (a documentar)

- GitHub Linguist (`languages.yml`)
- Python stdlib `http` (`HTTPStatus`, `HTTPMethod`)
- DevDocs (`https://documents.devdocs.io/{slug}/index.json`)
- Stack Exchange API (`/2.3/tags/{tags}/info`)
