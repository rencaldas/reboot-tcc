# Atribuições de fontes de dados

Cada fonte externa usada no jogo ou em qualquer outro dado do projeto entra aqui, com fonte, termos de uso e licença **verificados na própria fonte** — nenhum termo é presumido.

Este arquivo será preenchido à medida que cada fonte for incorporada ao projeto.

## Formato de cada entrada

```
## Nome da fonte

- **URL:** 
- **Licença:** 
- **Termos relevantes:** 
- **Data de verificação:** 
- **Uso neste projeto:** 
```

## Fontes conhecidas (a documentar)

- GitHub Linguist (`languages.yml`)
- Python stdlib `http` (`HTTPStatus`, `HTTPMethod`)
- DevDocs (`https://documents.devdocs.io/{slug}/index.json`)
- Stack Exchange API (`/2.3/tags/{tags}/info`)
